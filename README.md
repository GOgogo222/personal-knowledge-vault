# Obsidian Knowledge Vault

这是我的 Obsidian 知识库，按 PARA 架构整理，用来沉淀日记、项目、学习资料、读书笔记和知识卡片。

## 目录结构

```text
我的仓库/
├── 00-收件箱/      # 临时素材，待整理
├── 01-日记/        # 自动按 YYYY-MM-DD 命名
├── 02-周记/        # YYYY-Www
├── 03-项目/        # PARA 的 Projects
├── 04-领域/        # PARA 的 Areas
├── 05-资源/        # PARA 的 Resources
│   ├── 读书笔记/
│   ├── 知识卡片/
│   └── 学习/
├── 06-归档/        # PARA 的 Archives
├── 99-附件/        # 图片、PDF 等
└── 模板/           # 各类笔记模板
```

## 使用规则

- 新想法、新剪藏、新文件先放入 `00-收件箱/`。
- 有明确截止目标的内容放入 `03-项目/`。
- 需要长期维护的责任范围放入 `04-领域/`。
- 可复用资料、学习笔记、知识卡片放入 `05-资源/`。
- 完结、过期或暂时不用的内容放入 `06-归档/`。
- 图片、PDF、截图等附件集中放入 `99-附件/`。
