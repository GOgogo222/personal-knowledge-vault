# 个人知识库

这是一个用 Obsidian 管理的 Markdown 知识库，主要沉淀项目说明、学习日志、工具记录、读书/观影笔记和可复用知识卡片。

算法刷题不放在这里，已独立到 [cpp-algorithms-lab](https://github.com/GOgogo222/cpp-algorithms-lab)。

## 结构

- `00-收件箱/`：临时素材、网页剪藏和待整理资料。
- `02-日志/`：学习、工具配置、项目推进和实验过程记录。
- `03-项目/`：有明确目标、交付物或下一步动作的项目说明。
- `04-领域/`：需要长期维护的责任范围。
- `05-资源/`：读书/观影笔记、知识卡片和可复用参考。
- `06-归档/`：完成、过期或暂时不维护的内容。
- `99-附件/`：图片、PDF、截图等非 Markdown 文件。
- `模板/`：仍在使用的笔记模板。

## 整理规则

- 不确定归属的内容先进入 `00-收件箱/`。
- 过程记录放入 `02-日志/`，不要混进资源笔记。
- 需要推进的事项放入 `03-项目/`，结束后再归档。
- 能长期复用的资料放入 `05-资源/`。
- 根目录只保留仓库级入口文件。
