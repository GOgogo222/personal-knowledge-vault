# 硬件同类元器件候选库（实验室毕设版）

更新时间：2026-07-11

用途：为后续逐模块问答和最终选型提供候选池。优先考虑实验室内的演示效果、代码成熟度、接线难度和答辩可信度，不按户外工业量产标准过度设计。

## 使用说明

- 价格为调查时的参考价，库存和人民币售价会变化，下单前重新核价。
- 立创商城不少链接是裸芯片。实验室搭建时通常应购买已经焊接外围电路、接口和排针的成品模块。
- 替换难度：A=基本直接替换；B=需要改驱动、引脚或少量电路；C=需要重新设计PCB或系统架构。
- “同类型”不代表“可直接替换”。接口、供电、输出协议和测量对象必须同时匹配。

## 15. 当前实验室总体推荐

1. 主控：ESP32-S3 + ESP-WROOM-32。
2. 空气：PMS5003负责PM2.5；MQ135若保留，只显示相对气体响应。
3. 环境：AHT20 + BH1750。
4. 人体：LD2402，优先用UART读取完整信息。
5. 交互：1.54寸ST7789 IPS + INMP441 + MAX98357A + 4Ω/3W扬声器。
6. 灯光：12V白光LED灯带 + AO3400A类MOSFET + ESP32 PWM。
7. 喷雾：5V棉棒雾化器 + MOSFET开关。
8. 电源：12V/5A适配器，5V侧使用XL4015成品模块并留有余量。
