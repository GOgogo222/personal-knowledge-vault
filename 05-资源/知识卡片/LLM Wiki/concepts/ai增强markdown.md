# AI 增强 Markdown

## Overview

AI 增强 Markdown 指的是用 Markdown 作为可读、可编辑、可检索的知识载体，再让 AI 参与摘要、分类、链接、提问和改写。

## Why Markdown Works Well With AI

- 纯文本格式，便于脚本和 AI 直接处理。
- 标题、列表、链接和 frontmatter 都是清晰结构。
- Git 可以记录每一次修改。
- Obsidian 的双链让知识之间的关系显性化。
