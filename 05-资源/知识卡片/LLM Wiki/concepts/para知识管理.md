# PARA 知识管理

## Overview

PARA 是一种按用途组织资料的方法：Projects、Areas、Resources、Archives。它适合 Obsidian 这类文件夹式知识库，因为每个文件都可以按当前用途落位。

## Four Buckets

- **Projects**：有目标和截止条件的项目。
- **Areas**：需要长期维护的责任范围。
- **Resources**：可复用的主题资料和知识卡片。
- **Archives**：完成、过期或暂时不用的内容。

## In This Vault

- `03-项目/` 对应 Projects。
- `04-领域/` 对应 Areas。
- `05-资源/` 对应 Resources。
- `06-归档/` 对应 Archives。
