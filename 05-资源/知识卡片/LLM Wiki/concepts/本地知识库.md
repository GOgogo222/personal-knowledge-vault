# 本地知识库

## Overview

本地知识库是以本地文件为核心的个人知识管理系统。相比只把资料放在在线平台，本地知识库更强调可迁移、可备份、可检索、可由 AI 工具直接读取和维护。

## Why It Matters

- **个人语境**：记录自己的经历、项目、偏好、判断和表达方式。
- **长期复用**：资料不只服务当下问题，也能被未来任务重新调用。
- **AI 友好**：Markdown、目录结构、模板和链接让 AI 更容易理解上下文。
- **本地优先**：文件掌握在自己手里，便于 Git 备份和跨工具迁移。

## In This Vault

当前仓库采用 PARA 架构：

- `00-收件箱/` 用于捕获。
- `03-项目/` 用于推进有结束条件的任务。
- `04-领域/` 用于维护长期责任。
- `05-资源/` 用于沉淀可复用知识。
- `06-归档/` 用于降低活跃区噪音。
- `99-附件/` 用于集中管理非 Markdown 文件。
