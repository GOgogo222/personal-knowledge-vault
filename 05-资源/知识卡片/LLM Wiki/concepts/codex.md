# Codex

## Overview

Codex 是 OpenAI 的编程 Agent 系统。它不只是一个 CLI，而是逐渐扩展成包含本地终端、桌面 App、云端任务、GitHub 集成、自动化、代码审查和 MCP 工具连接的工程平台。

## Forms

- **CLI**：在终端中读写代码、运行命令、执行本地任务。
- **App / Desktop**：更像多线程任务指挥中心，适合管理多个工作流。
- **Cloud / Web**：把任务派到独立环境中运行，方便并行和审查。
- **Automation**：用于重复任务、监控、CI/CD 或后续提醒。
- **Review**：作为独立审查 agent 检查实现质量、安全风险或遗漏。

## Why It Matters

Codex 的竞争点不只是模型能力，而是能否把模型包进一个可靠、可审查、可自动化的工程系统。对个人知识库来说，它可以承担资料整理、链接修复、模板生成、索引维护和 Git 同步检查。
