# Obsidian

## 概述

**Obsidian** 是一款基于 [[../concepts/markdown|Markdown]] 的本地知识管理工具，支持双向链接、图谱可视化、插件扩展等功能。在 [[../concepts/ipo模型|IPO 工作流]]中，Obsidian 作为本地知识库的核心载体。

## 在 IPO 工作流中的角色

### 1. 信息收集中心
- `raw/` 目录：存放所有原始 Markdown 文档
- 通过 [[../concepts/obsidian剪藏助手|Obsidian 剪藏助手]]一键剪藏网页内容
- 支持 RPA 批量剪藏

### 2. 知识沉淀载体
- `wiki/` 目录：存放 [[../concepts/claude-code|Claude Code]] 生成的问答记录
- 本地化存储，永久保存
- 支持双向链接，形成知识网络

### 3. 内容创作基础
- 基于沉淀的问答进行二次创作
- 支持导出为多种格式（PDF、HTML 等）

## 核心优势

1. **本地优先**：数据完全掌握在自己手中
2. **Markdown 原生**：纯文本格式，永不过时
3. **插件生态**：丰富的社区插件支持各种场景
4. **双向链接**：构建知识图谱，发现知识之间的关联

## 关键插件

- [[../concepts/obsidian剪藏助手|Obsidian 剪藏助手]]：一键剪藏推特、公众号、网页
- [[../concepts/cloud-document-converter|Cloud Document Converter]]：飞书文档转 Markdown
