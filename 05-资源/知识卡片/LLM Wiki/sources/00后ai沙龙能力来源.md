# 00 后双非电商专业毕业，每周 4 场 AI 沙龙，我的能力从何而来？

> 原始来源：https://x.com/longdechen12/status/2036816359343222971  
> 作者：[[../entities/longdechen12|观自（@longdechen12）]]  
> 发布日期：2026-03-25

## 概述

[[../entities/longdechen12|观自]]分享了一套完整的 AI 时代知识变现工作流，核心是通过 **IPO 模型**（输入 → 处理 → 输出）在 3 小时内摸透一个领域的核心内容，并快速转化为培训课程、咨询方案等商业产品。

## 核心方法论：IPO 模型

### I - 输入（喂料）：打破信息壁垒（0.5~1 小时）

目标：将所有信息源转化为 AI 可理解的 [[../concepts/markdown|Markdown]] 格式。

#### 网页类工具

| 工具 | 适用场景 | 功能 |
|------|---------|------|
| [[../concepts/youtube-to-notebooklm|YouTube to NotebookLM]] | YouTube 视频 | 一键导入博主全部视频逐字稿到 NotebookLM |
| [[../concepts/obsidian剪藏助手|Obsidian 剪藏助手]] | 推特/公众号/网页 | 一键剪藏为本地 Markdown，支持 RPA 批量剪藏 |
| [[../concepts/cloud-document-converter|Cloud Document Converter]] | 飞书文档 | 破除权限限制，保存为 Markdown |

#### 视频类工具

**链接提取**：
- [[../concepts/get笔记|Get 笔记]]：B 站长视频、小宇宙播客、抖音博主全部视频逐字稿提取
- 自制 Claude Code app：一键导入抖音博主全部视频逐字稿到本地

**文件提取**：
- 下载狗/GreenVideo 下载视频 → [[../concepts/通义听悟|通义听悟]]提取逐字稿（通用底层方案）

### P - 处理（消化）：NotebookLM × Claude Code 联动（1~2 小时）

#### 为什么选 [[../concepts/notebooklm|NotebookLM]]？

1. **绝不产生幻觉**：完全基于真实材料生成，每个答案可溯源
2. **长文本处理能力强**：接入 Gemini 模型，支持上传 300 个文档
3. **输出格式丰富**：支持音频、视频、幻灯片等

#### 核心玩法：让 AI 帮你提问

**问题：** 大部分人不会提问，导致无法深入研究领域。

**解决方案：** 使用 [[../concepts/claude-code|Claude Code]] 批量生成问题清单。

**工作流程**：
1. 将所有 Markdown 文档放入 Obsidian 的 `raw/` 目录
2. 用 Claude Code 读取所有文档，生成 100 个问题清单
3. 将问题清单复制到 NotebookLM，批量提问
4. 用 Claude Code 将所有问答保存到本地 `wiki/` 目录

**优势**：
- 问题和答案永久沉淀在本地
- 可随时调用、扩展、二次创作
- 形成个人知识库，支持持续积累

### O - 输出（表达）：人机协作内容创作（0.5~1 小时）

#### 核心原则

> **用 AI 做研究，用人做表达。**

#### 工作流程

1. **框架搭建**：用 [[../concepts/xmind|Xmind]] 手搓思维导图，保证表达框架是自己的
2. **内容输出**：用语音输入法（[[../concepts/闪电说|闪电说]]）或语音转文字（[[../concepts/千问录音|千问录音]]）照着思维导图输出逐字稿
3. **幻灯片制作**：手搓 [[../concepts/keynote|Keynote]] 幻灯片（而非 NotebookLM 自动生成）

**为什么手搓而非 AI 生成？**
- 完全符合个人表达逻辑
- 手搓过程本身是梳理内容的过程
- 简约设计 + 动画渐进式显现，完美契合演讲节奏
- 保持"活人味"，避免 AI 生成的僵硬感

## 三大痛点与解决方案

| 痛点 | 解决方案 |
|------|---------|
| 不会提问 | Claude Code 批量生成问题清单 |
| 答案不可信 | NotebookLM 基于真实材料生成，可溯源 |
| 知识没有沉淀 | Claude Code 将问答保存到本地 wiki |

## 应用案例

- 录制国家工信部 AI 智能体证书课程
- 搭建湘江集团整套矩阵运营系统（六位数费用）
- 每周 4 场 AI 沙龙分享

## 关键洞察

1. **信息壁垒打破**：将所有信息源统一转化为 Markdown，消除平台、媒介、付费壁垒
2. **问题驱动学习**：好问题是深入研究的前提，AI 可以帮助生成问题清单
3. **知识沉淀**：本地化存储问答，形成可持续积累的个人知识库
4. **人机协作**：AI 负责研究和信息整理，人负责表达和创作
5. **快速迭代**：3 小时摸透一个领域，支持高频次内容输出
